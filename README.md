# HackShelf18 📚💻

🚀 A C++ project that unlocks hacking and Linux book recommendations — but only if you're 18 or older.

🔐 Age-based access:  
- ❌ Under 18? No access for you.  
- ✅ 18+? Welcome to the hacking bookshelf.

Books include:
- The Linux Command Line
- Linux Basics for Hackers
- Black Hat Python

Built with ❤️ for cybersecurity learners who earn their way to knowledge.
